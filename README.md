# Prime Stockfish vs Magnus

A polished static browser chess arena with a Prime Stockfish-themed interface and a fictional Magnus Carlsen challenge mode.

## Current build
- Playable chess board
- Legal move validation with chess.js
- Move history
- Evaluation display and bar
- Board flip and new-game controls
- Fictional Magnus-style lightweight opponent simulation

## Important
The Magnus opponent is a fictional simulation. It is not Magnus Carlsen, does not connect to him, and does not reproduce his private decision-making.

For true Stockfish analysis, a browser-compatible Stockfish WASM worker can be added later.
